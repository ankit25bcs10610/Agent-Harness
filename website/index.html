GET STARTED

Run Chiku from source.

The package is currently distributed as a source/development project, not as a public registry release.

git clone https://github.com/ankit25bcs10610/Agent-Harness.git
cd Agent-Harness
bun install
bun run dev

Set OPENROUTER_API_KEY in your environment before making provider requests. Never put credentials in browser code or commit them.

FAQ

Honest answers.

Does the website execute Chiku tools?

No. The demonstration is a labeled, prerecorded transcript. Anonymous visitors are never connected to a shell, filesystem, or provider credential.

Which providers are documented?

The current verified quick start uses OpenRouter. Check the provider source and guide before enabling another adapter.

Can I contribute?

Yes. Review the repository documentation, run the local checks, and open an issue or pull request on GitHub.
